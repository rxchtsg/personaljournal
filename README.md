# Personal Reflection Journal

This is my small journal project for my SE_19 module.
It has 3 HTML pages:
- index.html (home)
- entries.html (my journal entries)
- about.html (about me)

All pages are connected with a nav bar.
The site is responsive with 2 breakpoints:
- 900px
- 600px

To run it just open index.html in a browser.
=======
This is a basic backend for my reflection journal, built using Express.js.
It has three main routes:
/ → home page
/about → about page
/entries → shows a list of journal entries
